CICTrix design system

A visual companion to DESIGN.md, which remains the source of truth. Click any swatch to copy its hex. The toggle switches to the canonical dark palette (html[data-theme='dark']), which the app applies only inside the RSP module and settings.

Neutrals

Tailwind slate. The light column shows the classes components use; the dark column shows the html[data-theme='dark'] variables.

RoleLightClassDark
RuleUse slate, not gray-*. Switch gray to slate only when a file is touched for another reason. Don't add Bootstrap greys (#212529, #495057, #DEE2E6).

Status

A tinted fill with darker text of the same hue. These badges follow the current theme.

Approved For review Rejected In process Info
Approved Don't use a saturated fill with white text for status.
RuleBlue is reserved for brand and action. Info uses cyan so an info badge never reads as a button.

Score ratings

A fixed five-step scale for IPCR and applicant ratings, from the --score-*-text / --score-*-bg variables. Shown in light values.
