How this follows DESIGN_IDENTITY.md

  1. Portal chrome §8.2, §9.12. Same top bar, rail and compact hero as the RSP dashboard. The breadcrumb, title and period filters sit in the hero, and the KPI row overlaps it.
  2. KPI cards §9.7. Each card has a brand-tint icon chip, a sentence-case title and a 36px value. The submission rate card replaces "Completed evaluations" because it shows the same count against the total. Status appears only in the small badges, never as colored numbers.
  3. Color means something §1, §9.11. Passing ratings use brand blues (Outstanding is the deepest). Orange and red appear only for Unsatisfactory, Poor, below-target departments and overdue items, and each one has a text label.
  4. Tables §9.5. Numbers are right-aligned, departments sort worst first for submissions and best first for results, and the target line shows how far each department has to go.
  5. One primary action §9.1. Create Development Plans is the only filled button on the page. Everything else is a link.
  6. Not shown. The Action Required Queue stays as it is, below these sections. All numbers and names are sample data.
